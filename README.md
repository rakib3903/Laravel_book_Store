# Laravel Book Management System

A simple **Laravel project** to manage books with **user authentication**.  
Only authenticated users can **create, read, update, and delete books**.

---

## Features

- User authentication (register, login, logout)
- CRUD operations for books:
  - **Create** a book with `title` and `writer`
  - **Read** a list of all books
  - **Edit** book details
  - **Delete** a book
- Only authenticated users can perform CRUD actions
- Responsive UI built with **Tailwind CSS**

---

## Requirements

- PHP >= 8.1
- Composer
- Laravel 12.x
- MySQL or any other supported database
- Node.js & NPM (for compiling assets with Tailwind)
